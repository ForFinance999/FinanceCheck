# Finance Telegram Mini App

Мобильное приложение личных финансов для Telegram, опубликованное как статический сайт на GitHub Pages.

## Текущее состояние

- Telegram WebApp API и определение пользователя;
- dashboard с капиталом, счетами, вкладами и месячными итогами;
- чтение счетов, операций и вкладов из Supabase REST API;
- расчёт текущей стоимости вкладов с капитализацией;
- адаптивная навигация и демо-режим вне Telegram.

> Временное ограничение: Telegram `initData` пока не проверяется на сервере, а RLS-политики прототипа небезопасны. До реального использования нужен серверный слой проверки подписи.

## Локальный запуск

Откройте проект через любой статический HTTP-сервер. Сборка не требуется.
